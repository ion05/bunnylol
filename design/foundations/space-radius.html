Layout — each of these has a recorded reason
--layout-max: 900px — the options shell.
--popup-w: 380px — fixed, because a popup that resizes while you type reads as broken.
--popup-list-h: 268px — a fixed height, not a max: the box keeps its size as matches come and go.
--row-h: 36px / --row-h-popup: 32px — minimums, so a two-line row still grows.
Elevation
There is no shadow token. Every surface is separated by a 1px border or by a sunken fill. The dispatch toast — the one element that floats — uses a border for the same reason.
