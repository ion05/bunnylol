Inputs and controls

Inputs sit on the sunken fill with a --control-border edge, which is the token that exists to clear WCAG 1.4.11’s 3:1 for control edges. Focus is shown forced on.

Light
Text
Mono — anything the user types that a machine reads back
Invalid — border plus a message, never a message alone
A keyword cannot contain a space. Separate keywords with a comma.
Select — one SVG chevron
One data URI, not two stacked gradients. A data URI cannot resolve currentColor and light-dark() takes colours rather than images, so the stroke is a single #8a8a82 — 3.10:1 on the light sunken fill, 5.07:1 on the dark one.
Checkbox — “include this in a set”
Switch — “this thing is on or off”
The two are not interchangeable. A checkbox picks members of a set (which engines to intercept, which packs to enable); a switch turns one shortcut on or off. The knob carries a 1px dark ring because it is --bg on a sand track when checked — 2.4:1 without it.
